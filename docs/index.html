Pipeline

Copilot 每次更新，字典都能跟上

i.
使用即审计

运行时自动记录漏翻文案到本地报告

ii.
筛选

curate.mjs 剔除代码与测试噪音，只留真实 UI 文案

iii.
翻译

人工或 LLM 翻译缺口，落到 gap/*.json

iv.
合并

merge_dict.py 注入字典与动态模式，语法校验

v.
热换生效

替换 zh-CN.js，重启 App 即全量中文
